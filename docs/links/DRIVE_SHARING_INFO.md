# Google Drive sharing

- **Folder:** `SmartLock_Project_Complete_2026-09-29`
- **Access:** anyone with the link, **Viewer** (read and download only)
- **Purpose:** the primary share and download link for the whole SmartLock project

## Content policy

This folder contains **sanitized** material only:
- no LINE Channel Access Token, LINE User ID or LINE Basic ID
- no Wi-Fi password, Admin PIN or browser credentials
- no personal email
- no Google Apps Script or Sheet IDs
- no raw git history

Redacted values appear as `<redacted-…>`. Test fixtures in `tests/` use obvious mock values (for example `mock_token_…`, `U0123456789abcdef…`, PIN `2468`).

The private team-only archive, which includes the raw git history, is kept separately and is **not** shared by link.
